# Font licences

Both typefaces are self-hosted (no request to a font service) and licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

- **Atkinson Hyperlegible** (Regular, Bold), Copyright 2020 Braille Institute of America, Inc. Latin subset, from the Fontsource packaging.
- **Manrope** (variable), Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope). Latin subset, from the Fontsource packaging.

Hindi (Devanagari) and Kannada text uses the device's own fonts (Noto Sans Devanagari/Kannada, Kohinoor, Kannada Sangam MN, Nirmala UI), because neither typeface covers those scripts.
